./build.sh # one module per env into www/ (or ./build.sh pong flappy)

python3 -m http.server -d www # open http://localhost:8000, ?env=pacman picks a game

With the same seed, the wasm build dreams the same episodes as the native build, frame for frame, at 1–5 ms per frame depending on the game. Each module carries its game's default agent; TWF_AGENT=... ./build.sh picks another. The keys are the same as on the Pico, plus arrow keys and on-screen buttons, and f runs the dream as fast as it can, which helps while learning (l).
