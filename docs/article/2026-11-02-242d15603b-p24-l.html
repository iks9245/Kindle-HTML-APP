| | | I went and researched this, and found that basically none of the TV brands were anything but creepy on privacy. What I’ve ended up doing was I got an LG and never hooked it up to Wifi/internet, and then use an Apple TV to watch things on. It’s a bit annoying if I want to switch to a game console as Apple TV can’t control the TV’s input channel, but otherwise works very well. Make sure the TV supports HDMI CEC. |
