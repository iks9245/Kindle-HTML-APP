We ran AI agent swarms in Minecraft and Mindustry

When games got intense and it was ambiguous, GPT agents would fetch the public code of Mindustry from the web (which was allowed in their sandbox) and try to write scripts, analyze for weaknesses, etc. This did not let them alter the source code of the game; it was just a way for them to understand all the units and mechanics at a source level. The GPTs openly collaborated in their chat, discussing what unit or code they found that they could potentially use to switch up strategies. This was never disallowed, but they were never told to do this either. The Claudes never searched up game code from the web.
