He would go on to write numerous papers, some with Chung, on the mathematics of juggling. But back in 1971, decades before he made that connection explicit, he posed a question that some mathematicians now say might have been inspired by juggling, too.

Start with a random set of different integers, not including zero. Can you always rearrange them so that if you add up the first two numbers, then the first three, then the first four, and so on, every “partial sum” turns out different? In the language of juggling, this would mean that if each ball stays in the air for a different amount of time, you can always find an order to throw them in such that two balls won’t come crashing down on the same beat — which would ruin the act.
