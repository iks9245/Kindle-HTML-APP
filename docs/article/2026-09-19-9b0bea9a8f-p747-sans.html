- Read-only bash commands with glob patterns (e.g. ls *.ts ) and commands starting withcd && no longer trigger a permission prompt

- Suggest the closest matching subcommand when claude is invoked with a near-miss typo (e.g.claude udpate → “Did you meanclaude update ?”)
