Accuracy on recorded data wasn't enough. An agent drives the dream into states the data never had, and any mistake there is something it can exploit. So the main check runs while an agent plays: read the game state back off the dreamed frame (games/.py: read), apply the real rules to that state and the agent's action, and compare the result with the next dreamed frame and reward.
