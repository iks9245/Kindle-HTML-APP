- Memory safe with zero annotations. No lifetime

syntax, no aliasing or exclusivity rules, no unsafe. The

compiler infers what every reference is rooted in and rejects references

that could outlive their owners.

- Nested data stays inline. A string, an array of strings, a record with variable-size fields and an array of those records are each one contiguous block with no pointer in it. A record that is 160 bytes and an allocation in C++ is 29 bytes and none in Goose.
