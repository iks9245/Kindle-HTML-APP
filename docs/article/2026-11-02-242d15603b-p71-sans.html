| | | Got a Bravia TV for cheap back in 2014 that happened to be pre-Android TV (and pre-Google TV) so Android TV was just released and those something-else-os were "outdated". Sony stopped releasing security patches a while back and there are no longer apps whatsoever and they all were crap - the youtube one was pure torture because of how slow it was and the web browser was just as miserable as ie6. But besides that I can send it commands to it via its IP and control it, consume stuff via a DLNA daemon, do screen mirroring, and all the usual tv stuff. The image quality and sound are still great after 10+ years though I can't care less about oled 4k 120Hz and all that stuff. So it's no longer a "smart" tv but it's not also so "dumb" for a now dumb tv. |
