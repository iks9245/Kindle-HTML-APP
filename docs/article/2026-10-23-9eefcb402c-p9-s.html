Command line tool to compress the game assets into convenient binary files. Combines images, models, sound files, shaders into a single binary file with a structure designed for fast data retrieval.

Once upong a time Hedra used to support multiplayer. It worked by doing UDP Hole Punching and having clients communicate P2P, this server was in charge of that. You might also see some networking remnants in the Engine code.

The build process is pretty straightforward.

- Checkout all the submodules

- Run the build depedencies scripts

- Compile the C# solution

You can check the GitHub actions workflows for some examples on Linux and Windows.

延伸問答

遊戲開發者為何會選擇在高中時期投入如此大規模的遊戲專案？

該專案最初是為了學習OpenGL的運作方式。然而，隨著時間推移，專案範圍不斷擴大，最終演變成一個功能齊全的3D遊戲和遊戲引擎，展示了作者對學習與創造的熱情。

Hedra的「程式化生成世界」具體是如何運作的，為何不需要世界存檔？

Hedra的世界是基於體素(voxel)的，並使用Marching Cubes演算法從體素中提取連續的表面。由於整個世界都是在執行時根據世界種子(world seed)即時生成的，因此遊戲只需保存玩家的內容和世界種子，無需單獨的世界存檔文件。

遊戲引擎強調的「模組化支援」對玩家來說意味著什麼？

模組化支援意味著玩家可以透過Python腳本等方式自由地擴展和修改遊戲內容，例如新增釣魚等功能。開發者特意將遊戲設計為基於引擎的模組，藉此確保模組API始終保持更新，鼓勵玩家社群參與內容創作。
