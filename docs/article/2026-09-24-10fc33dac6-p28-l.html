Biology Might Not Be Quantum, but Its Math Is Quantumlike

Singer and colleagues showed in 2025 that introducing oscillations into a particular kind of simple neural network makes them more efficient and robust. Singer said that using interference essentially gave the network a new dimension to work with: time. This was because the phase of an oscillation encodes information about how events are structured in time relative to each other. After the workshop, Singer said he was “impressed by the fact that some real-world phenomena are maybe better described using the description techniques they use in quantum physics.”

Xavi Bou
