- Added ANTHROPIC_DEFAULT_MODEL environment variable: sets the model new sessions start on, while a/model pick still overrides it and persists across restarts (unlikeANTHROPIC_MODEL )

- Added notify_when_idle to cross-sessionSendMessage : ask another Claude Code session on this machine to send one notice when it next goes idle — opt-in, one-shot, no polling (macOS and Linux)

- Sandbox: on macOS, wildcard read-deny rules (e.g. **/.env ) now take precedence inside allowed read regions, cover matched directories’ contents, and can’t be bypassed by renaming the denied file
