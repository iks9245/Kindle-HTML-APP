How to run your own swarm (we open sourced it!)

- Multi-Agent Mindustry: the game environments from this post. To get started, read the README, or give the link to your agent with “help me understand and set this up”, as we’ve included everything it needs. It requires just a model provider API + a harness + compute (e.g. locally on your MacBook or remote sandboxes) to run.

- Multi-Agent Harbor: the framework that runs them, our fork of Harbor, the open-source framework behind Terminal-Bench. Our fork runs multiple agents in any environment. We use it for a variety of things (enterprises, industrials, etc.), and it’s very useful for game-based multi-agent simulations like this one. For more on the framework, point your agent at it.
