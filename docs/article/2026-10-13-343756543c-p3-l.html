I turned my unused Kindle into a photo frame with GPT-6 Astra

I first tried GPT-5.6 Sol with reasoning effort set to Extra High. It wrote code to connect to the Kindle but couldn't resolve an error that prevented it from storing data on the device. Then I tried Fable 5.1 and Opus 5.5, but Anthropic's cybersecurity safeguards blocked each attempt after two prompts. Finally, I tried GPT-6 Astra with reasoning effort set to High. We were able to jailbreak the Kindle.

We used the existing jailbreak code as a reference to build our own tools for running custom software on the Kindle. Then we created and installed the slideshow app.
