延伸問答

為什麼要引入 AGENTS.md，它與 CLAUDE.md 有何不同？

AGENTS.md 的引入是為了在專案中未設定 CLAUDE.md 時提供靈活性，作為替代的專案指令文件。這允許開發者為其 Claude Code 專案選擇不同的指令文件命名規範，或為特定類型的代理行為和指令指定不同的配置來源，以更好地管理專案設定。

更新提到「尚未在 Bedrock、Vertex 或 Foundry 上線」是什麼意思？這些平台的重要性為何？

Bedrock、Vertex 和 Foundry 可能是指與 Claude AI 服務相關的雲端平台或部署環境，例如 AWS Bedrock 或 Google Cloud Vertex AI。此限制表示 AGENTS.md 的支援功能目前僅在 Claude Code 的獨立部署或特定環境中可用，尚未推廣到這些主要的雲端整合平台，這對在這些平台上使用 Claude 服務的用戶來說是需要注意的差異，意味著他們暫時無法利用此新功能。

此次更新主要解決了哪一類型的問題？

此次更新頻繁解決了關於會話穩定性、錯誤報告機制、文件處理工具行為以及配置解析相關的問題。例如，修復了會話可能掛起或無結果退出、文本內容塊為空導致請求失敗、API 金鑰或配置值格式錯誤引起的啟動問題，以及各種工具（如 Write、Edit、Grep）的錯誤處理和行為異常。這些修正共同提升了 Claude Code 的可靠性和用戶體驗。
