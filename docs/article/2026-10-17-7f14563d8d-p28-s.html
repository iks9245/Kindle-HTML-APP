Here are the memory stores we visited, with their capacities when we query with a stored key and the keys and values are random:

| Memory store | $f(x)$ | Capacity | Capacity at $d_k = 64$ |

|---|---|---|---|

| Outer product | $V\transpose K x$ | $d_k$ | 64 |

| Optimal linear | $V\transpose K (K\transpose K)\inverse x$ | $2d_k$ | 128 |

| ReLU MLP | $V\transpose \operatorname{ReLU}(Kx)$ | $2d_k$ | 128 |

| Squared ReLU (GLU MLP) | $V\transpose \operatorname{ReLU}(Kx)^2$ | $2d_k^2/3$ | about 2,700 |

| SwiGLU MLP | $V\transpose \parens*{\operatorname{Swish}(Kx) \odot Kx}$ | about $2d_k^2/3$ | about 2,900 |

| Cubed ReLU | $V\transpose \operatorname{ReLU}(Kx)^3$ | $2d_k^3/15$ | about 35,000 |
