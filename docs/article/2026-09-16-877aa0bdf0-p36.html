延伸問答

為什麼作者團隊能在短短一個月內完成通常需要數年的 GPU 驅動程式開發？

團隊利用先前開發的虛擬機進行 macOS 逆向工程，並透過對硬體進行探測和追蹤來理解 AGX 韌體 ABI 及使用者空間元件，而不是直接查看 Apple 的二進制檔案。這種高效的「潔淨室」方法結合專業知識，大大縮短了開發時間。

成功開發此 Linux GPU 驅動程式對 M4 Mac Mini 和 MacBook Neo 的未來有何意義？

這項成功意味著 M4 Mac Mini 和 MacBook Neo 在運行 Linux 時將能獲得完整且高效能的圖形加速支援。這不僅能大幅提升這些裝置在 Linux 環境下的可用性和使用者體驗，也為開源社區在 Apple Silicon 上實現更全面的 Linux 支援奠定了基礎，未來可能還會進一步支援 Vulkan。

驅動程式開發過程中最大的技術挑戰是什麼？

驅動程式開發中最具挑戰性的部分是逆向工程 AGX 的韌體 ABI (應用程式二進位介面)。Apple 的設計將核心驅動程式切半，一部分放入 AGX 韌體，另一部分則透過共享記憶體中交錯複雜的結構體進行通訊，導致理解和實作其互動模式極為困難。
