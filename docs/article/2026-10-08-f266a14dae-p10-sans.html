Categorically speaking, Option is the coproduct 1 + Walrus, which is either nothing or a walrus. A function that takes an Option and branches inside is really a function out of a coproduct, and by the universal property of coproducts such a function is exactly a pair of functions, one for each summand. Pushing the if up factors that pair apart: the caller deals with the 1 summand, and the core function is just the Walrus component.
