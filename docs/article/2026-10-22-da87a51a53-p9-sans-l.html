- Compensating controls if using AWS WAF:

- For CVE-2026-109618 Use the SizeRestrictions_BODY rule in the AWS WAF Core rule set (CRS) managed rule group that blocks request bodies that are over 8 KB (8,192 bytes).

- For CVE-2026-109619 Add the following custom rule to your WebACL to protect your application against the leverage attempts until your application is patched. The rule matches on POST requests that contain the PHP_SESSION_UPLOAD_PROGRESS in the body, and PHPSESSID in either the body or cookie. We will be updating the AWS WAF PHP Managed Rule Group shortly.
