延伸問答

這些 PHP 漏洞 (CVE-2026-109618 及 CVE-2026-109619) 的具體性質是什麼？

這些是允許遠端程式碼執行的嚴重安全漏洞。攻擊者無需身份驗證即可透過特製的網頁請求來利用這些漏洞，進而可能在受影響的 PHP 運行時上執行任意程式碼、讀取敏感資料或造成服務阻斷。這類問題通常與不安全的輸入處理有關。

AWS 服務本身是否受到這些漏洞的影響？客戶需要採取哪些行動？

AWS 服務本身並未受到這些漏洞的直接影響。然而，在 AWS 環境（例如 Elastic Beanstalk、Amazon Linux 或 Lightsail）中部署並使用受影響 PHP 版本的客戶則會受到影響。客戶應根據其所使用的 AWS 服務，遵循相關指南進行 PHP 版本升級或應用 AWS 提供的緩解措施。

對於使用已終止支援 (EOL) PHP 版本的用戶，應如何應對這些未獲修復的漏洞？

對於已終止支援且沒有上游修復程式的 PHP 版本 (5.4-8.1)，唯一的完整解決方案是立即將應用程式遷移到受支援且已修復的 PHP 版本分支。雖然可以應用一些臨時的配置控制措施來減少部分漏洞的影響，但這不是全面的保護，且 CVE-2026-109618 在 EOL 分支上沒有任何修復方案。
