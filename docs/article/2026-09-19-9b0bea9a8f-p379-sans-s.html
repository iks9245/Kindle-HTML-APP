Redacted unlessOTEL_LOG_ASSISTANT_RESPONSES=1 ; when that var is unset it followsOTEL_LOG_USER_PROMPTS , so deployments that already log prompt content will start receiving response content on upgrade — setOTEL_LOG_ASSISTANT_RESPONSES=0 to keep prompts-only.
