延伸問答

Delta 與現有程式碼協作工具相比，主要的創新或改進之處為何？

Delta 透過其 DeltaDB 技術，將程式碼與對話即時連結，讓所有評論都能緊密地附著於不斷演進的程式碼上，而不是傳統工具中容易過時的程式碼快照。這確保了開發者和 AI 代理在整個開發過程中都能保有完整的語境和決策歷史。

文章中提及的 DeltaDB 具體是什麼，它如何與開發者現有的 Git 工作流程整合？

DeltaDB 是一個即時同步對話和程式碼工作樹的數據庫系統。它與現有的 Git 儲存庫無縫協作，在每次提交之間捕捉所有的編輯和對話，因此開發者可以像往常一樣提交和推送，而未使用 Delta 的隊友仍能看到標準的 Git 儲存庫。

Delta 與現有的 Zed 編輯器有何關聯？DeltaDB 未來是否也會整合到 Zed 中？

Delta 是一個全新的應用程式，雖然它與 Zed 秉持相同的性能與工藝原則，但它被設計為 DeltaDB 的首個客戶端，以不受現有編輯器限制地迭代。儘管 Delta 是 DeltaDB 的起點，開發團隊仍會繼續開發 Zed，並且 DeltaDB 最終也會整合到 Zed 編輯器中。
