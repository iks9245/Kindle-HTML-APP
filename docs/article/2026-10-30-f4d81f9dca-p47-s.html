So that was the first indication that we had something. And then we started imaging. So we had been perfecting these imaging algorithms on synthetic data. We’d fed these algorithms made-up data. So we would take a black hole image that we might be looking at. We’d corrupt it with noise, and we’d send it through these algorithms, and we’d refine these to the point where we were pretty confident in these algorithms.

But before we set these loose on the data, we also realized that human error or human groupthink could be a really big problem. So we split our teams up into four groups. Each group had the data, but they could not talk to each other because we wanted to make sure that we all weren’t in the same room thinking like, “I see a ring. Do you see a ring? I see a ring.” And it’s not a ring, right?
