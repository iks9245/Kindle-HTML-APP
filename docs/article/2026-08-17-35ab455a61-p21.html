延伸問答

如果網站擁有者不希望 Cloudflare 注入分析腳本，他們應該如何操作？

網站擁有者應確保其域名在 Cloudflare DNS 設定中設為「僅限 DNS」（灰色雲朵圖標），而非「代理」（橙色雲朵圖標）。此外，如果已啟用代理，則需要在 Cloudflare 分析儀表板中手動啟用網站分析後再將其停用。

Cloudflare 為何會採取這種預設注入分析腳本的做法？

文章中提到，Cloudflare 可能認為其 CDN 代理服務是大多數用戶使用的預期預設功能，因此傾向於預設啟用相關服務。然而，許多用戶認為這應該是選擇啟用而非選擇停用的功能。

Cloudflare 靜默注入分析腳本對用戶網站的隱私和安全性有何潛在影響？

這種做法引發了對用戶數據隱私的擔憂，因為它在未經明確同意的情況下收集了網站訪客的分析數據。更廣泛地看，如果 Cloudflare 能夠在網站內容中注入腳本，理論上它也能夠監視加密流量，這對於網站的數據完整性和安全性構成潛在風險。
