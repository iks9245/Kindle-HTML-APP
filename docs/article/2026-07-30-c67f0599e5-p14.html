延伸問答

既然 k3-256k 更經濟，那 Kimi Code 目前提供哪些主要模型，它們之間有何區別？

Kimi Code 主要提供 Kimi K3 (包含 k3 和 k3-256k 版本) 及 Kimi K2.7 Code (包含 kimi-for-coding 和 kimi-for-coding-highspeed 版本)。K3 是旗艦模型，擁有強大推理能力和更大的上下文視窗（K3-256k 則專注於成本效益）；K2.7 Code 則擅長程式碼補全與常規開發，其中高速版輸出速度更快。

使用 k3-256k 時，有哪些特別的使用情境或注意事項需要了解？

k3-256k 適用於日常問答、程式碼補全、常規功能開發和單一或小型檔案編輯，但不支援影片輸入。在從 K3 (1M) 切換至 k3-256k 時，若上下文已超過 256k 或包含影片檔，建議先手動壓縮上下文以避免資訊丟失或切換失敗，並獲得更持久的配額效益。

如果在使用新模型後發現配額消耗增加，或者無法訪問某些模型功能，可能原因是什麼？

模型切換後，舊的上下文快取會失效，需要重新預填充，導致初期用量顯得較高，建議開啟新會話以獲取最佳體驗並降低消耗。此外，若請求的能力超出會員方案權益（如會員等級不足或上下文視窗大小限制），伺服器會返回 401 錯誤，用戶可能需要升級方案。
