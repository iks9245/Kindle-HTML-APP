vphone-cli exposes a host control socket (/vphone.sock) for programmatic control — screenshots, touch, swipes, hardware keys, clipboard — each action returning an inline screenshot for AI-driven E2E testing. See vphone-mcp for an MCP server wrapping it.

延伸問答

「vphone-cli」的運行需要哪些特定的硬體和軟體環境？

它需要搭載 Apple Silicon 的 macOS 15 (Sequoia) 或更高版本作業系統。此外，還需安裝 Xcode 及 iOS SDK，並且系統的安全保護機制（SIP/AMFI）可能需要放鬆，以允許使用未簽署的二進位檔案和私有權利。

為什麼這項工具對於iOS研究和開發特別重要？它能實現哪些傳統虛擬機無法做到的功能？

該工具的價值在於它能提供深層次的系統控制，允許安裝自訂韌體和多種安全繞過補丁，甚至實現全面越獄。這使得開發者和研究人員能夠在虛擬環境中測試和分析通常受限於物理裝置的行為，例如系統級別的修改和安全漏洞的探討。

「vphone-cli」提供的不同「變體」（variants）有何區別，這些變體對虛擬機的功能有何影響？

「vphone-cli」提供「less」、「regular」、「dev」、「jb」和「exp」等多種變體。這些變體代表不同程度的系統修補和安全繞過，從僅保留 iOS 緩解措施的「less」模式，到包含完整越獄（如自動安裝 Sileo、TrollStore）的「jb」模式，甚至還有用於反虛擬機偵測研究的「exp」模式，為使用者提供靈活的控制能力。
