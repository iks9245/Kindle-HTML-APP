We called the project KindleCTL. On my Kindle, I open "Photo Slideshow" from the same screen where I choose my books. It cycles through ten photos, showing each for four minutes. When I want to read, I exit the slideshow and return to my books.

I used Codex and T3 Code on my Mac to work with the coding agents.
