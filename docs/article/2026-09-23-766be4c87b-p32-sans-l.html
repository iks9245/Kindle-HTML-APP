延伸問答

SAML 究竟是什麼，它最初的用途是什麼？

SAML 是「安全斷言標記語言」的縮寫，它是一種基於 XML 的標記語言，用於交換安全斷言資訊。它由 OASIS 於 2002 年創建，旨在為網路服務提供一種標準化的方式，讓使用者可以透過單一登入 (SSO) 驗證身份，特別是在 Web 2.0 初期學術界和企業對此需求旺盛。

為什麼 OpenID Connect (OIDC) 被認為是比 SAML 更好的替代方案？

OIDC 被視為更好的替代方案，主要是因為它比 SAML 更簡單、更現代。SAML 基於複雜的 XML，尤其其 XML 簽章驗證被認為是其核心問題和安全漏洞的來源，而 OIDC 則建立在更輕量級的 JSON Web Token (JWT) 和 OAuth 2.0 框架上，這使其更容易實作和維護，也較不易出現安全設計缺陷。

對於希望從 SAML 遷移的組織來說，有哪些建議的步驟？

對於服務供應商 (SP)，建議直接支援 OIDC 並避免使用 SAML。對於身份或認證供應商 (IdP)，則應制定詳細的淘汰計畫，包括向客戶溝通、停止為新客戶提供 SAML 整合、為現有客戶提供 OIDC 配置替代方案，並設定一個最終停用日期。
