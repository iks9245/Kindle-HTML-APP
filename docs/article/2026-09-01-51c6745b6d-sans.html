延伸問答

什麼是 MV2 和 MV3？Google 為何要從 MV2 轉換到 MV3？

MV2 和 MV3 是 Chrome 擴充功能開發者用來構建擴充功能的不同架構版本，其中 MV 代表 Manifest 版本。Google 推動 MV3 是為了提高瀏覽器擴充功能的安全性、隱私保護和效能，並為開發者提供更現代的開發平台。

廣大用戶如果依賴像 UBlock Origin 這類 MV2 擴充功能，現在該怎麼辦？

對於已經安裝的 MV2 擴充功能，它們可能會繼續工作一段時間，但無法再接收更新或重新安裝。用戶應尋找已升級到 MV3 的替代擴充功能，或等待開發者發布其 MV3 版本。UBlock Origin 等受歡迎的擴充功能通常會有 MV3 替代方案或官方升級路徑。

這種從 MV2 到 MV3 的轉變是否引起了爭議或批評？

是的，這種轉變引起了社群的廣泛爭議，特別是關於 MV3 對某些類型的擴充功能（尤其是廣告阻擋器）功能限制的擔憂。批評者認為，MV3 的某些 API 限制可能會削弱廣告阻擋器的效力，或增加開發複雜度，進而影響用戶的瀏覽體驗。
