PHP web runtimes (CVE-2026-109618 and CVE-2026-109619)

Bulletin ID: 2026-143-AWS

Scope: AWS

Content Type: Important (requires attention)

Publication Date: 10/21/2026 14:30 PM PDT

Summary:

Two critical issues have been identified in PHP web runtimes (CVE-2026-109618 and CVE-2026-109619) that can allow an unauthenticated actor to run code on affected systems. A remote caller can send crafted web requests to affected PHP workers and execute arbitrary code, read process-accessible data, or cause denial of service.
