Every version of every row (tuple) stored in a Postgres table has an associated ctid value. ctid is short for "current tuple identifier." Any row inserted or updated gets a new ctid. It is a 48-bit number that directly identifies a tuple's physical location in the Postgres heap. Represented textually as (, ), the upper 32 bits indicate the block number and the lower 16 indicate the offset within that block. From now on, we will refer to the part as the "page number" or "page."
