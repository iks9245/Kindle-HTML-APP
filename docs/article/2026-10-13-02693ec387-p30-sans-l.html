If asked ‘How many things exist?’ we’d probably say that there are a great many things indeed – a cat here, a house there, some protons, electrons, and so on – one might even think that there are infinitely many things. But Spinoza argues that there is just one thing. If we hold that there exists more than one thing, we must say something about what each of these things is like. So, we might say ‘This cat is black,’ ‘That house is made of brick,’ ‘Socrates is wise’ and so on. Crucially, for the advocate of the PSR, the different things that exist cannot have all the same properties. If two things, this table and that table, for example, are distinct, there must be some explanation of their distinctness that appeals to some difference between them, some difference in their properties (eg, one is square, the other oval).
