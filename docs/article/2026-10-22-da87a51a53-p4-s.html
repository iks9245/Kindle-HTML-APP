- Amazon Linux: Updated PHP packages are targeted for 2026-10-22. Customers running PHP on Amazon Linux should apply the updated packages as soon as they are available. Please follow CVE-2026-109618 and CVE-2026-109619 in the Amazon Linux Security Center for details.

- Amazon Lightsail: Updated Lightsail blueprints are expected on 2026-10-21. AWS cannot update running Lightsail instances in place. Customers running PHP workloads on Lightsail should create new instances from the updated blueprints and migrate their applications following the documentation.

Mitigation Guidance:

- Upgrading immediately to a patched PHP release is the only complete fix: 8.5.12, 8.4.27, 8.3.36, or 8.2.35. The configuration changes below may reduce impact for customers who cannot update immediately, but none is a complete mitigation.

- Refer to Security advisory: Critical remote code execution vulnerabilities, update now for additional mitigations.
