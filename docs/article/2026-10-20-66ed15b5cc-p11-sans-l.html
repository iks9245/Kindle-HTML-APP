Multiple pure tone noise (aka “buzz saw” noise), created by rotor locked shocks present when the fan blade tip speed is supersonic, can be estimated with the MPT code. The MPT codes also use flow predictions from a Computational Fluid Dynamics (CFD) code as input. This tool can be used by engineers to study the real-world effects of blade-to-blade difference caused during fabrication (manufacturing variations) or during hot-running operation (blade setting angle and untwist variations). Copies of the MPT code can be requested from NASA’s Software Catalog.
