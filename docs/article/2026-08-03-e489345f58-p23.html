延伸問答

Kakehashi 專案的開發目的是什麼？它主要解決了哪些痛點？

Kakehashi 旨在提供一個在 Linux aarch64 環境下執行 macOS ARM64 二進位檔的實驗性使用者空間轉譯層。它主要解決了開發者在非 macOS 平台上運行或測試 macOS 應用程式的困難，為跨平台開發和自動化測試提供了新的可能性。

Kakehashi 在技術實現上與其他作業系統相容層有何不同？

Kakehashi 的技術特點在於它是一個命令列優先的解決方案，並且不依賴即時編譯器 (JIT)。它透過載入 Darwin Mach-O 執行檔、映射一個獨立的 libSystem 並直接轉譯 BSD 系統呼叫來運行 macOS 程式，這使其在某些方面與其他依賴 JIT 或更複雜虛擬化的專案有所區別。

目前 Kakehashi 已經支援哪些 macOS 應用程式？未來有何發展計畫？

目前 Kakehashi 已成功驗證可執行 7-Zip 的多執行緒壓縮和 curl 的 HTTP/HTTPS 請求等基礎應用。未來計畫包括支援 Xcode 工具鏈中的 Git、整合 Apple Security.framework、以及對 GUI 應用程式和程式碼簽章的支援，以擴展其應用範圍。
