延伸問答

既然 Android 系統也是基於 Linux 核心，為什麼作者還要特意從 Android 切換到「Linux 手機」呢？

雖然 Android 使用 Linux 核心，但其上層是 Google 的專有框架和服務，缺乏真正的開放性與用戶控制。切換到純粹的 Linux 手機，是為了擺脫這些專有組件，獲得更完整的開源體驗、系統級別的自由度和更佳的隱私保護。

轉用 Linux 手機對日常使用會有什麼主要的挑戰或犧牲？

轉用 Linux 手機的主要挑戰包括應用程式生態系統不成熟，許多主流應用程式可能無法原生運行；硬體驅動支援有限，可能導致部分功能不穩定；以及整體用戶體驗可能不如 Android 或 iOS 流暢和便利。用戶可能需要投入更多時間進行客製化和問題排解。

目前有哪些主流或較為成熟的 Linux 行動作業系統可供選擇？

目前較為人知的 Linux 行動作業系統包括 Purism 的 PureOS (用於 Librem 系列手機)、Pine64 的 postmarketOS (支援多款舊型 Android 設備)，以及 Ubuntu Touch (由 UBports 社群維護)。這些系統都致力於提供開放、注重隱私的行動體驗，但各自的生態發展程度不一。
