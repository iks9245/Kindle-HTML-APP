| | | Buy any TV you want, ignore all instructions to connect it to the internet, then look for an HDMI port on the back. Plug an HDMI cable into one end, and in the other end plug in a cheap Linux computer like a used Intel NUC from ebay. Then use a nice air-mouse remote like the Pepper Jobs W10. I watch any movie or TV show I want in 4k via Kodi, but then can alt tab to a Terminal or a real web browser. Privacy, and dramatically more functionality than any TV would ship with anyway. Using this setup to type this message right now on pc hooked to a projector in my garage from my couch. It turns out we never needed Smart TVs in the first place. Just treat it as a screen for a desktop computer. |
