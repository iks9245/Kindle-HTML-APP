- Plain C in, plain C out. Goose compiles to one C

file, so it runs wherever a C compiler does and calls C directly through

extern fn. The bundled TinyCC backend compiles and runs a

program in-process, with no build step.

The tutorial walks through all of this by example, the reference covers the whole language topic by topic, the specification has the exact rules, and the benchmarks have the numbers, losses included.
