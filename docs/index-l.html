Google open-sources TorchTPU, a native PyTorch back end for TPUs

Google 近期開源了 TorchTPU 專案，為 Google 的張量處理單元 (TPUs) 提供原生的 PyTorch 後端，讓使用者能直接在 TPU 裝置上運行 PyTorch 模型和操作。這項整合彌補了 PyTorch 與 TPU 之間的鴻溝，透過自訂 ATen 核心和編譯快取等功能，顯著提升模型訓練和推論的效率。對於希望利用 TPU 強大運算能力的 PyTorch 使用者而言，這是一個重要的進展。 - 提供原生 PyTorch 後端，直接支援 Google TPUs。 - 內含自訂 ATen 核心與編譯快取，優化執行效能。 - 支援分散式訓練，並提供多種模型範例。

TorchTPU 解決了什麼問題，為何這項發布很重要？

TorchTPU 解決了 PyTorch 模型難以直接利用 Google TPU 高性能運算能力的問題。過去 PyTorch 使用者若想在 TPU 上執行模型，需要更複雜的轉換或橋接。透過提供原生的後端整合，TorchTPU 讓 PyTorch 開發者能更便捷、高效地利用 TPU 進行模型訓練與推論，從而加速深度學習專案的進程。

哪些類型的使用者或專案最能從 TorchTPU 中獲益？

主要受益者是那些使用 PyTorch 開發大型深度學習模型的研究人員和開發者。特別是當他們需要處理大規模數據集、追求更快的模型訓練速度，或希望在 Google Cloud 環境中利用 TPU 的專用硬體加速時，TorchTPU 能提供顯著的效能提升和成本效益。

開發者要如何開始使用 TorchTPU，有什麼基本要求？

開發者可以透過 pip 在 Python 虛擬環境中安裝 `torch_tpu`，並確保使用 Python 3.11 或更高版本。建議在 TPU 虛擬機 (如 v6e GCE 實例) 上運行。專案提供了詳細的使用指南和互動式 Marimo 筆記本，其中包含分散式訓練和模型推論的範例，有助於快速上手。

FarmFlux任務的具體目標是什麼？

為什麼NASA認為農業排放很重要且需要更多研究？

NASA研究人員正在開發一種名為roamx-0201的新型火星直升機旋翼葉片設計，旨在讓未來的火星直升機飛得更高、更遠，並攜帶更多科學儀器。這項發表於9月22日的研究成果顯示，經過優化的新葉片設計比「機智號」的葉片能顯著提升空氣動力學性能，有望將單次飛行距離從0.7公里擴展至18.7公里。 此設計還改善了在火星稀薄大氣中的失速性能，使其能在更廣泛的飛行角度下安全操作，為火星探測開闢新可能性。 - 新葉片（roamx-0201）透過更薄、不對稱的形狀和特殊擾流技術提高升力。 - 顯著延長單次飛行距離，並改善失速性能，提升飛行安全性及操作範圍。

「機智號」（Ingenuity）火星直升機對NASA的火星飛行計畫有何重要意義？

「機智號」是NASA的首架火星直升機，歷史性地首次在地球以外的星球上實現了動力飛行。它成功證明了在火星稀薄大氣中進行航空探索的可行性，為後續更大型、更複雜的火星直升機任務奠定了技術和操作的基礎。

新的 roamx-0201 葉片設計將如何影響未來的火星探索任務，例如 SkyFall 之後的計畫？

roamx-0201 葉片設計旨在大幅提升火星直升機的性能，使其單次飛行距離能從「機智號」的0.7公里擴展至18.7公里，並能搭載更多科學儀器。這將使未來的火星直升機（如SkyFall之後的任務）能夠探索更廣闊的區域、抵達更多樣化的科學目標，從而解鎖新的科學發現。

相較於地球，火星的稀薄大氣對直升機飛行造成了哪些獨特挑戰，而 roamx-0201 葉片是如何克服這些挑戰的？

火星大氣極為稀薄，導致直升機難以產生足夠的升力，且火星音速較低，易使旋翼遭遇「阻力發散」。roamx-0201葉片透過其更薄、不對稱的創新形狀，以及故意擾亂邊界層以產生額外升力的設計，有效提升了升力。此外，它顯著改善了「失速」性能，讓直升機在更廣泛的飛行角度下也能保持穩定和安全，從而克服了這些嚴峻的挑戰。

How intuitions work

這篇文章探討日常直覺（如「直覺不對勁」）的理性力量，認為它們並非不理性或僅是啟發式工具，而是我們理解世界不可或缺的認知能力，其運作方式與感知類似。作者主張，直覺能直接呈現事物的本質，為我們的信念提供基礎性證成，如同視覺經驗為我們提供關於世界的理由。這種能力與哲學領域中受重視的「理性直覺」本質相同，只是應用情境與控制程度不同。 * 直覺和感知一樣，能直接呈現事物並帶有「真實感」，為信念提供非信仰的理由。 * 日常直覺與哲學思想實驗中的直覺，在認知本質上是一致的，都反映了事物「看起來是如此」的預判。

哲學家們通常如何定義「理性直覺」，以及他們為何更專注於研究這類直覺？

哲學家們通常透過「看起來是如此」(seemings) 來描述理性直覺，例如在智性上感覺「2 + 2 = 4」是如此。他們過去主要關注這些直覺，因為它們被認為主要作用於哲學、邏輯和數學等先驗學科，被視為一種更純粹的理性認知形式。

文章提到直覺（或感知）有助於解決知識論中的「倒退問題」。這個問題具體是什麼？直覺如何提供解決方案？

倒退問題指的是，如果每個信念都需要另一個信念來證成，這將導致證成鏈條無限延伸而永無止境。為了解決這個問題，哲學家提倡基礎主義，認為有些信念無需依賴其他信念來證成。直覺和感知經驗正是這種非信念狀態，它們本身就能為我們的信念提供初步的證成，作為證成鏈條的起始點。

既然直覺並非萬無一失，我們如何區分那些可靠的、具有理性力量的直覺，與僅僅是衝動或偏見的非理性感受？

文章指出，直覺的證成力量可以被「擊敗」，例如當有證據表明我們的認知系統出現問題，或身處欺騙性環境時。儘管直覺本身提供證成，但其有效性並非絕對，它需在更廣泛的證據和理性考量下進行評估，並可能被反駁性的理由所推翻，這顯示了其批判性檢視的必要性。

A vocabulary for the future: nature

法國哲學家布魯諾·拉圖爾（Bruno Latour）挑戰了將「自然」與「人工」或「人造」嚴格劃分的傳統觀點。他認為這種劃分是一種道德判斷而非本體論的區分，將自然視為好的，而其對立面則為壞的。拉圖爾建議，我們應重新思考世界不僅由人類行動者所影響，也居住著其他具有能動性的存在，這意味著自然與人類世界比我們通常認為的更加糾纏不清。這段影片與加泰隆尼亞導演的視覺作品結合，具體呈現了拉圖爾所質疑的這種界線崩潰，暗示兩者之間的緊密交織。 要點： - 質疑「自然」與「人工」的二元對立 - 強調非人類能動性與世界萬物的糾纏性

拉圖爾為何認為「自然」與「人工」的劃分是道德判斷而非本體論判斷？

他指出這種劃分將「自然」神聖化為「好」，而將人造物貶低為「壞」，這阻礙了我們對人類與非人類複雜互動的理解。這種道德傾向限制了對世界真實面貌的認識，無法客觀地看待兩者之間的關係。

在拉圖爾的脈絡中，「非人類能動性」具體指的是什麼？能否舉例說明？

「非人類能動性」指的是除了人類之外，其他自然實體或科技產物也能夠產生影響和改變。例如，氣候變遷對人類社會造成的廣泛衝擊，或是社交媒體演算法（一種科技產物）如何塑造公共輿論，都展現了其獨立於人類意圖之外的能動性。

重新思考「自然」與「人工」的二元對立，對於我們處理環境議題或科技發展有何潛在影響？

這可能促使我們採取更整合、更負責的態度。例如，在環境保護上，我們不會單純地將人類活動視為對自然的破壞，而是尋求與自然系統共存及互惠的方式；在科技發展上，會更重視技術與其生態和社會環境的共生關係，而非孤立地追求進步，從而促成更永續的解決方案。
