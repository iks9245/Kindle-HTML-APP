脈絡

Decisions API 是一個用於快速評估文字、圖像或兩者的工具，能以比 Responses API 快十倍的速度返回特定類型的答案。這項服務的目標是幫助應用程式進行內容分類、請求路由以及工作優先排序，目前處於公開測試階段，並僅支援 gpt-6-luna 模型。

重點

  • Decisions API 能以極快的速度處理輸入，提供比傳統回應 API 更高效的決策能力。
  • 它支援同時評估文字和圖像內容，使其適用於更廣泛的應用場景，如產品檢測。
  • API 提供「判斷式 (predicate)」、「選擇 (choice)」和「評分 (score)」三種核心問題類型。
  • Decisions API 專注於返回預定義的答案類型，與用於生成自定義 JSON 結構的 Responses API 或用於調用工具的 Function Calling 有所不同。
  • 該 API 僅對輸入 tokens 收費，不產生緩存讀寫或輸出 tokens 的費用，有助於成本控制。

影響與延伸

Decisions API 的推出預示著應用程式能更快速、更自動地處理大量輸入並做出決策，顯著提升營運效率。這對於需要即時分類、審核或路由的場景（如內容審核、客服分流、品質控制）尤其重要，有望降低人工干預的需求並加速業務流程。

小辭典

Decisions API
一種高效能的 API，專為快速評估文字或圖像，並返回特定答案類型（如機率、選擇或評分）而設計。
gpt-6-luna
目前 Decisions API 唯一支援的模型，負責執行內容評估和決策生成。
Predicate question (判斷式問題)
一種問題類型，用於檢查某個條件是否為真，並返回該條件為真的機率（0 到 1 之間）。例如，檢查產品是否有可見損壞。
Zero Data Retention (ZDR) (零資料保留)
一項資料隱私功能，確保提交給 API 的資料不會被永久儲存，以保障客戶的資料安全性。
