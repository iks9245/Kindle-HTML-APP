Postgres LISTEN/NOTIFY actually scales

DBOS 公司成功優化了 PostgreSQL 的 LISTEN/NOTIFY 功能，駁斥了其不具擴展性的說法。透過解決 NOTIFY 期間的全局排他鎖瓶頸，他們將單一 PostgreSQL 伺服器上的串流寫入吞吐量從每秒 2.9K 提高到 60K 次，同時保持毫秒級延遲，使其在實時應用中更具實用性。 - 優化方案涉及緩衝和批處理通知，顯著減少了全局鎖的爭用。 - 為了確保可靠性，引入了低頻率的備用輪詢機制，以應對通知緩衝期間可能出現的丟失情況。

為何 Postgres 的 LISTEN/NOTIFY 功能最初被認為不具擴展性？

文章指出，核心問題在於 PostgreSQL 為了保證通知按照事務提交順序發送，在提交包含 NOTIFY 的事務時會取得一個全局排他鎖。這個鎖在事務完全提交並寫入磁盤前不會釋放，導致高並發寫入時出現嚴重的瓶頸。

描述 DBOS 公司實現的優化方案如何大幅提升了 LISTEN/NOTIFY 的性能。

優化方案主要透過緩衝和批處理 NOTIFY 操作來解決全局鎖的瓶頸。它將多個單獨的通知在記憶體中累積，然後定期地以單一批量事務的形式進行刷新，從而大幅減少了全局鎖被取得的頻率和爭用。

該優化方案在可靠性方面如何處理潛在的問題？

由於通知被緩衝在記憶體中，如果進程在通知刷新前崩潰，可能會導致部分通知未被傳遞。為了解決這個問題，DBOS 引入了一個備用機制，讀取器除了等待通知外，還會定期對資料庫進行低頻率的輪詢，以檢查是否有資料更新但通知未送達的情況。

ESCAPADE任務的核心科學目標是什麼？

ESCAPADE任務的核心科學目標是研究太陽風（來自太陽的百萬英里每小時物質流）如何與火星環境相互作用，以及這種相互作用如何驅動火星大氣層的流失。太空船預計在2027年9月抵達火星，對此進行深入探測。

熱紅外影像揭示了地球被太陽部分照射的陰影半球，因大氣和地表自身熱量而發光，溫度約在零下10至零下44華氏度。相較之下，缺乏絕緣層的月球遠側則顯得極為寒冷，溫度約為零下280華氏度。這不僅是對相機的校準，也提供了地球和月球熱特性的寶貴數據。

ESCAPADE太空船前往火星的旅程規劃為何？

ESCAPADE太空船目前停泊在地球百萬英里外的拉格朗日點2。它計畫於2026年11月飛越地球，利用地球的重力助推效應（gravitational slingshot）加速，最終在2027年9月抵達火星軌道。

NASA Announces New Spacecraft Technology Demonstration Mission at Moon

NASA宣布與業界合作，將於2027年啟動CAPSTONE 02任務，此為一項關鍵的太空船技術示範任務，旨在月球軌道上展示交會對接、近距離操作、自主導航及地月空間通訊能力，並將繼續探測月球周圍的輻射環境。這項任務使用兩艘小型太空船，將支援NASA的Artemis計畫及未來的月球基地，對於確保太空人往返月球表面時的安全太空船對接至關重要。 * 將驗證比低地球軌道更複雜的相對導航技術。 * 測試在地球和月球引力共同作用下的三體軌道飛行器軌跡。

什麼是最初的CAPSTONE任務，它實現了哪些成就？

最初的CAPSTONE任務（Cislunar Autonomous Positioning System Technology Operations and Navigation Experiment）是美國首次商業月球任務，也是第一艘在月球近直線暈軌道運行的太空船。它成功驗證了地月空間的通訊、網路和自主導航能力，為CAPSTONE 02奠定基礎。

為什麼CAPSTONE 02任務中測試的這些先進導航和對接技術對Artemis計畫和月球基地至關重要？

這些技術對於Artemis計畫中的太空人安全地往返月球表面至關重要，因為它們使太空人能夠在地月軌道上與月球著陸器精確對接。地月空間的獨特引力條件無法在地球上完全複製，因此必須透過實際飛行測試來建立所需的持久能力，以實現月球的永久存在。

什麼是「三體軌道」，CAPSTONE 02任務為何要特別研究它？

「三體軌道」是指太空船在地球和月球引力同時作用下的軌跡。CAPSTONE 02任務透過精確的編隊飛行和對接操作，旨在更深入理解這些複雜軌道，這對於確保太空船在月球周圍的長期穩定運行和未來深空任務的導航策略至關重要。

Signal then storm

這篇文章概述了科學家艾倫·巴斯鮑姆（Allan Basbaum）長達半世紀的科學探索，他致力於在神經系統中定位疼痛的起始點與終止機制。其研究核心在於理解疼痛訊號如何從單純的「訊號」演變為難以控制的「風暴」狀態，特別是針對慢性疼痛的發生與發展。巴斯鮑姆的長期努力旨在揭示疼痛的關鍵神經途徑，為未來的疼痛管理與治療提供新的見解。 關鍵研究方向： - 探索疼痛的起源與終止機制 - 理解從急性訊號到慢性疼痛「風暴」的轉變過程

定位疼痛起源點的主要挑戰是什麼？

定位疼痛起源點的挑戰在於疼痛感知是一個複雜的過程，涉及多種神經通路與大腦區域的相互作用，而非單一的物理位置。此外，慢性疼痛的機制往往與急性疼痛不同，使其識別與治療更為困難。

理解疼痛訊號如何演變為「風暴」對於疼痛治療有何意義？

理解這一轉變過程對於開發更有效的慢性疼痛治療至關重要。它可以幫助科學家們識別關鍵的干預點，在疼痛惡化為難以控制的狀態之前，及早阻斷或調節其進程，從而改善患者的生活品質。

巴斯鮑姆在長達50年的研究中，可能會採用哪些類型的研究方法？

在長期的疼痛研究中，巴斯鮑姆可能會採用多種方法，包括神經生理學實驗、分子生物學分析、動物模型研究以及對人類疼痛患者的臨床觀察。這些方法旨在從不同層面揭示疼痛訊號的傳導、處理與調節機制。
