Safari introduces Adaptive Dark Mode in 27.3

Safari 27.3 beta 版推出了「自適應深色模式」（Adaptive Dark Mode），旨在解決約40%的深色模式使用者面臨的網站深色版本支援度不足（僅約10%）的問題。 此功能會自動分析並將淺色網站轉換為深色模式，提供更一致的深色瀏覽體驗。 * 自動將淺色網頁內容轉換為深色模式。 * 透過智慧色彩轉換確保內容可讀性與可用性。 * 保護使用者隱私，網站無法偵測此模式是否啟用。

「自適應深色模式」主要解決了什麼問題？

此模式主要解決了深色模式使用者在瀏覽不支援深色模式的網站時，體驗不一致的問題。儘管許多人偏好深色模式，但絕大多數網站並未提供深色版本，導致使用者在深色系統設定下，仍會遇到刺眼的淺色網頁。

該功能如何確保網站內容在轉換後仍能保持良好的可讀性和外觀？

「自適應深色模式」的核心在於顏色轉換，它使用色彩矩陣來反轉顏色的亮度，同時保留色調，確保文字達到足夠的對比度。此外，它還會智慧處理SVG和位圖圖像，僅在必要時轉換以避免破壞視覺完整性，並在某些情況下關閉CSS效果以維持元素可用性。

網站開發者是否可以選擇不讓自己的網站受到「自適應深色模式」的影響？

是的，網站開發者可以透過在HTML中加入 `` 標籤，或在CSS中使用 `color-scheme: light only` 規則，來告知瀏覽器該頁面或特定元素應只以淺色模式顯示，從而避免被「自適應深色模式」轉換。

Believing and thinking

這篇文章深入探討了政教分離原則的合理基礎，指出其核心不在於宗教信仰的內容，而是宗教信條（religious credence）與事實信念（factual belief）之間存在根本的心理學差異。作者認為，事實信念是無意識的、受證據驅動的，而宗教信條則是自願選擇、不依賴證據且常在心理上被區隔開來。 這項區別至關重要：它解釋了為何政府不應基於宗教制定政策，因為宗教信條不具備民主審議所需的普遍可驗證性；同時，它也支持了宗教自由，允許個人在私人領域保有這些可區隔的信條。 * 事實信念：無意識、受證據影響、普遍可驗證。 * 宗教信條：自願選擇、不受證據限制、具心理區隔性。

文章提到「宗教信條」與「事實信念」在心理上有所不同，能否舉例說明它們在日常生活中具體的差異？

事實信念如「獅子吃肉」是基於證據且不由自主的，即便提供金錢也難以改變。相反地，宗教信條如「相信耶穌」則是個人可以選擇或轉換的，且即使缺乏證據或證據相反，信仰者仍能堅定不移。

如果宗教信條不適合作為公共政策的基礎，那麼當公民的道德信念與其宗教觀點深度結合時，民主政府應如何處理？

文章指出，政府需預設某些道德信念（如謀殺是錯的），但當公民因宗教動機提出政策主張時，應將其論點描述性地轉化為普遍可驗證的事實，使其能被理性與證據檢視。這樣能確保政策辯論具備公共對話的基礎，而非單純的信仰衝突。

文章主要以美國為例，這種「宗教信條」與「事實信念」的心理區隔及其對政教分離的影響，在全球其他國家（特別是有國教的國家）是否也同樣適用？

作者認為這種區隔是普遍存在的心理現象，其對政教分離的啟示在全球各地均可見。即使是設有國教的英國，也對國教在公共領域的權力設有嚴格限制。這表明，無論政府結構如何，此心理區隔有助於解釋為何將私人宗教動機與公共政策理由區分開來是合理的。
