「金星帶」是什麼，它是如何形成的？

「金星帶」是一種在日出或日落時分，與地球陰影帶相對的粉紅色反曙暮光弧。它是由於太陽光穿過地球大氣層後，被大氣層中的灰塵和氣體散射而形成的現象，通常呈現出微妙的粉紅色或橙色。
