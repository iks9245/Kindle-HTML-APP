Compression is prediction

2026年8月11日，一篇名為《壓縮即預測》的文章指出，資料壓縮演算法與大型語言模型（LLMs）的核心任務在於預測，從而達成減少資訊量的目標。文章闡述了現代壓縮工具（如轉換、模型和熵編碼器）如何運作，並強調了模型在根據符號頻率建立機率分布方面的關鍵作用。雖然LLMs在預測能力上表現出色，但其龐大的模型大小和運算成本使其不適用於一般資料壓縮任務，但兩者從根本上都體現了相同的數學原理。 * 壓縮與LLMs的訓練目標皆為預測並最小化資訊量（熵）。 * 傳統壓縮技術雖然高效，但LLMs的預測能力揭示了更深層次的共同點。

為什麼文章說資料壓縮與大型語言模型（LLMs）的核心任務都是「預測」？

傳統資料壓縮透過識別並移除資料中的重複或冗餘模式來縮小檔案，這本質上是在預測接下來可能出現的資料。同樣地，LLMs透過學習語言模式來預測下一個最有可能的詞或字元，從而生成連貫的文本。兩者都是基於對資料模式的「預測」來達到其目的。

既然LLMs在預測上表現出色，為何文章又說它們不適用於一般的資料壓縮任務？

儘管LLMs有強大的預測能力，但它們通常規模巨大，需要數GB甚至數TB的儲存空間，並消耗大量的運算資源。對於壓縮網頁回應等日常任務，這些成本遠遠超過了壓縮所能帶來的效益，因此傳統且輕量級的壓縮演算法（如gzip）仍然是更實際的選擇。

文章中提到的「熵」與LLMs的「交叉熵」有何關聯，它們在壓縮與語言模型中扮演什麼角色？

在資料壓縮中，「熵」衡量的是資料的最小不可壓縮大小，即資料的真實資訊量。壓縮的目標是將資料壓縮至接近其熵值。而LLMs訓練時最小化的「交叉熵」，本質上也是在最小化模型預測與實際資料分佈之間的差異，這與壓縮中減少「每符號位元數」的目標相同，都旨在使模型更有效地預測資料。
