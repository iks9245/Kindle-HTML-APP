1. AI 公司 Anthropic 為何會封鎖用戶帳戶？

2. 新平台 HackerTube 的影片內容主要來自哪裡？

HackerTube 的影片內容完全來自於2007年以來在Hacker News討論中被推薦的影片，提供由技術社群策展的獨特體驗。

3. Linux 核心中發現的 CVE-2026-98432 漏洞有何嚴重性？

此漏洞的 CVSS 評分高達 9.8，允許遠端未經身份驗證的攻擊者執行任意程式碼，甚至可能取得 root 權限，對未修補的系統影響廣泛且具高危險性。

4. 烏克蘭前線城市奧列什基的居民，是如何成功從俄羅斯佔領區撤離的？

數百名居民是在美國前第一夫人梅蘭妮亞·川普斡旋下的人道停火協議中，經由俄羅斯和白俄羅斯路線，成功撤離到烏克蘭切爾尼戈夫地區。
