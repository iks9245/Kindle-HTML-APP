1. Google 最近對 Android 開源專案 (AOSP) 的原始碼取得方式做了什麼改變？這項改變帶來了什麼主要擔憂？

Google 最近將用於 AOSP 專案的某些原始碼的 Git 標籤，取代為透過 Google Drive 取得。這項改變令人擔憂原始碼的完整性與真實性驗證變得困難，並引入了單點故障。

2. 澳洲外交部長黃英賢為何對以色列表達「憤怒」？

她對以色列決定不起訴涉嫌殺害澳洲援助人員 Zomi Frankcom 的責任人表示「憤怒」。Frankcom 在加薩的一次以色列空襲中喪生，儘管以色列國防軍承認是嚴重失誤，澳洲仍認為此決定遠未達到所期望的問責制。

3. 烏克蘭前國防部長米哈伊洛·費多羅夫提出了什麼重要呼籲，這對澤倫斯基總統的執政權力帶來了什麼挑戰？

他公開呼籲在戰時舉行總統大選，強調「民主不能被俄羅斯綁架」。此舉被視為自俄羅斯全面入侵以來，對澤倫斯基總統執政權力最大的挑戰。

4. NASA 科學家在關於月球南極的研究中有了什麼重要發現？這項發現引發了什麼主要擔憂？

NASA 科學家發現，與人類相關的微生物很可能在月球南極的陰暗、寒冷區域中存活。這項發現引發了對未來月球化學或外星生命探索可能受到地球微生物污染的擔憂。
