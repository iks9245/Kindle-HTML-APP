先想一下答案，再點開題目對照：

1. AMD 收購 AI 晶片新創公司 Taalas 的主要目的是什麼？

AMD 收購 Taalas 旨在透過將 AI 模型直接蝕刻到矽晶片中，大幅提升 AI 推理效能。此舉將創造出模型專用的積體電路。

2. 為慶祝《雷神之鎚》(Quake) 30週年，id Software 與哪個合作夥伴推出了什麼新的遊戲內容？

id Software 與 MachineGames 合作推出了全新的免費遊戲篇章「機械黎明」。此更新為玩家帶來19個全新地圖、敵人變體及武器。

3. 美國新墨西哥州法官對 Meta 公司處以高額罰款的主要原因是什麼？

Meta 因未能就旗下平台對兒童構成的危險發出警告而被罰款。法官將其平台對兒童造成的心理傷害和剝削比作「公害」。

4. NASA 的 SkyFall 任務計畫將多少架直升機送往火星？這些直升機的主要科學目標是什麼？

NASA 計畫將三架「天降號」火星直升機送往火星。其主要目標是收集地表下雷達數據和近紅外圖像數據，以推進火星探索任務。
