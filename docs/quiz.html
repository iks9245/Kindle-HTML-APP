1. eBay因針對某位女士的騷擾活動被判罰，這導致了什麼樣的財務後果？

eBay被裁定需支付5600萬美元的巨額賠償金。此判決凸顯了企業對員工行為監管的責任及其高昂代價。

2. Kakehashi這項實驗性工具的主要功能是什麼？它如何實現讓macOS軟體在Linux上執行？

Kakehashi旨在讓macOS ARM64二進位檔在Linux aarch64環境下運行。它透過載入Darwin Mach-O檔案、映射獨立的libSystem並轉譯BSD系統呼叫來實現，且無需即時編譯器(JIT)。

3. 過去70年間，針對英語學習者的核心詞彙表（如GSL和NGSL）在詞彙類型上發生了哪些主要變化？

舊的詞彙表移除了許多具體、實體世界的詞彙，而新的詞彙表則增加了大量抽象概念的詞彙，反映了日常生活與社會結構的演變。

4. 美國總統川普宣布取消對伊朗的計劃性大規模打擊，他提出了什麼條件？

川普表示，他取消打擊的條件是伊朗能「迅速」達成協議。他聲稱伊朗及其他中東國家已就協議「初步範圍」達成一致，但伊朗否認了這一說法。
