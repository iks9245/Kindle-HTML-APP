1. 奧克拉荷馬州的聯邦法官對Flock Safety系統的使用做出了什麼重要裁決？

法官裁定，在沒有搜查令的情況下使用Flock Safety系統搜尋車牌侵犯了第四修正案權利，稱其為「不分青紅皂白的大規模監控」，並壓制了因此獲得的證據。

2. Anthropic的最新模型Opus 5.5在Claude應用程式中有哪些關鍵改進，以及指南建議使用者如何調整提示詞策略？

Opus 5.5顯著提升了處理長期、多步驟任務的能力，且能自主思考。指南建議在單一訊息中提供完整的任務與明確的「完成線」，並移除冗餘指令如「仔細思考」。

3. 田納西州監獄長Frank Strada辭職的原因是什麼？

他是在死囚Christa Pike的處決失敗後辭職的。Pike在被注射兩劑致命藥物後倖存，此事件促使州長下令獨立審查並暫停該州所有處決。

4. 阿聯酋總檢察長是如何描述Flydubai航班上一名副機長襲擊機長事件的性質？

阿聯酋總檢察長將此事件定性為「恐怖主義行為」。該副機長用應急斧襲擊機長並企圖控制飛機，導致飛機驟降17,000英尺，後經乘客制服、備用機師操作才安全降落。
