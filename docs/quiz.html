4. 根據最新研究，珊瑚如何主動獲取氧氣？當水溫升高時，為何反而會導致珊瑚窒息死亡？

珊瑚透過微小的纖毛主動製造水流漩渦來獲取氧氣。然而，高溫會導致纖毛過度擺動，消耗自身過多氧氣並輸送缺氧水體，最終使珊瑚窒息死亡。
