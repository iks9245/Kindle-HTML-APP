1. Safari 27.3 beta 版推出的「自適應深色模式」主要目的是什麼？

此功能旨在解決約40%的深色模式使用者面臨的網站深色版本支援度不足的問題。它會自動分析並將淺色網站轉換為深色模式，提供更一致的深色瀏覽體驗。

2. 西班牙交通部長奧斯卡·普恩特為何在近期宣布辭職？

他在馬德里附近發生一起造成至少69人死亡的致命高鐵事故六天後宣布辭職。此舉是為了回應公眾對國家高鐵系統安全性的嚴重質疑和日益增長的政治壓力。

3. 幣安遭受的63億美元加密貨幣竊盜案，駭客是透過什麼方式入侵系統的？

駭客透過複雜的多階段社會工程攻擊，包括冒充假招聘面試，誘騙一名工程師下載惡意軟體。他們還利用受感染的電腦和幣安內部的AI工具來入侵其系統。

4. 近日歐洲多架客機遭遇的疑似炸彈威脅，最終結果如何？

儘管這些威脅造成航班改道、延誤及旅客疏散，但所有威脅最終都被證實為惡作劇，並未發現任何爆炸物。各國當局正在合作評估這是否為旨在擾亂空域的協同攻擊。
