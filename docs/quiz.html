1. OpenAI近期發布的Navier-Stokes方程式證明，AI輔助的「形式化驗證」時間有何顯著變化？

透過AI輔助，原本可能需要數萬小時的形式化驗證工作，現在僅需數十小時即可完成，大幅降低了驗證成本與時間。

2. 在AI普及的時代，文章指出企業建立競爭優勢的「新護城河」是什麼？

文章指出，在AI讓複製變得輕而易舉的時代，「點子」和「創造力」成為企業建立真正商業價值和競爭壁壘的護城河。

3. 根據亞馬遜貨機在佛羅里達州墜毀的事故數據，造成此次事故發生的主要原因之一是什麼？

新發布的飛行數據顯示，其中一名飛行員曾多次就「過度速度」發出警告，但飛機最終仍以偏高的158節速度著陸，衝出跑道墜毀。

4. 美國國家航空暨太空總署（NASA）部分開發的「搜救衛星輔助追蹤系統」（SARSAT）最主要的救生功能是什麼？

SARSAT系統能透過接收個人定位信標（PLB）發出的遇險信號，並將警報傳達給搜救協調中心，從而在沒有手機信號的偏遠地區協助挽救生命。
