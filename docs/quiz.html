先想一下答案，再點開題目對照：

1. 韓國修訂後的《個人資訊保護法》對大規模數據洩露的最高罰款比例有何調整？

對於因故意或嚴重過失導致1000萬人或更多個人數據洩露的公司，罰款將從原先銷售額的3%提高至最高10%。

2. Claude Code 在專案中缺少 CLAUDE.md 檔案時，會改為讀取哪個文件作為專案指令？

當專案中沒有 CLAUDE.md 時，Claude Code 將改為讀取 AGENTS.md 作為替代的專案指令文件。

3. 法國總統馬克宏警告俄羅斯對歐洲的混合式攻擊加劇，其目的是什麼？

馬克宏指出，俄羅斯混合式攻擊的目的是恐嚇歐洲並削弱其對烏克蘭的支持。

4. 美國與丹麥就格陵蘭安全達成的協議，賦予了美國哪些關鍵權利？

該協議賦予美國在格陵蘭永久控制安全的能力，並有權單方面建立額外的軍事設施。
