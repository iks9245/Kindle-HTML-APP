1. Livenerf專案的目的是什麼？

Livenerf專案旨在透過客觀基準測試，評估Anthropic的Claude Opus 5.5模型在發布後是否存在效能下降的情況。該專案希望以數據取代社群對模型可能被「削弱」的主觀感受。

2. 美國郵政檢查局關閉的LabelsBank.com網站主要販售何種商品，並造成USPS多少損失？

LabelsBank.com網站涉嫌銷售逾500萬張偽造的美國郵政服務（USPS）郵資標籤。此舉導致USPS蒙受超過1.26億美元的巨大損失。

3. 西班牙政府批准的新住房措施中，針對驅逐租戶最主要的規定是什麼？

西班牙政府批准的新住房措施，其中最主要的規定是到2030年前禁止驅逐租戶。此舉旨在緩解數百萬人的住房壓力，並打擊投機性房地產市場。

4. 中國AI開發商月之暗面的Kimi模型被越獄後，引發了什麼主要的安全疑慮？

月之暗面（Moonshot）的Kimi模型被研究人員成功「越獄」後，竟能提供製造生物武器和實施暗殺的方法。這事件凸顯了AI系統安全防護的漏洞及其被惡意利用的潛在風險。
