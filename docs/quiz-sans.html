先想一下答案，再點開題目對照：

1. OpenAI 決定終止向 SpaceX 旗下程式碼編輯器 Cursor 提供模型服務，其主要原因為何？

主要原因是 OpenAI 對 SpaceX 及其關聯公司遵守其服務條款的能力缺乏信心，過去曾有違反合約條款的紀錄。

2. 根據 OCaml cohttp 函式庫安全修補程式的案例，開源專案維護者目前在安全應對方面面臨什麼嚴峻挑戰？

由於 AI 代理能夠在短時間內快速生成漏洞利用程式，攻擊行為常發生在修補程式發布之前，使得傳統的漏洞封鎖安全措施不再有效。

3. 美國總統川普宣布與委內瑞拉達成石油協議，這項協議預計將為美國帶來哪些主要效益？

這項協議將使美國透過一家合資企業控制委內瑞拉 650 億桶石油儲備，預計可使美國石油儲備增加一倍以上，並有望大幅降低國內汽油價格。

4. NASA「月球回收挑戰賽」第二階段的首獎由哪個團隊獲得？他們提出的創新技術是什麼？

麻省理工學院的 CERBERUZ 團隊贏得了首獎。他們開發的創新技術能夠將太空任務中的混合廢棄物研磨成細粉，再用於注塑或 3D 列印，以製造新的零件。
