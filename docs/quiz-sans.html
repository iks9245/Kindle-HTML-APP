先想一下答案，再點開題目對照：

1. Bend語言的主要目的是什麼？

它是一種新型程式語言，旨在透過形式化證明來防止AI在程式開發中產生錯誤，確保其程式碼能精確匹配人類意圖。

2. 美國國家航空暨太空總署（NASA）公開的第一架太空梭軌道器叫什麼名字？它在太空梭計畫中扮演了什麼角色？

它被命名為「企業號」（Enterprise）。它本身未設計用於太空飛行，但所進行的大氣層測試飛行，為1981年太空梭計畫首次載人太空任務奠定了基礎。

3. 加拿大對歐盟提出成為其第一個「準會員」的提議有何反應，以及此提議的目的是什麼？

加拿大總理表示歡迎此提議，並呼籲雙方在國防、關鍵礦物和能源安全方面加強合作，以強化面對地緣政治挑戰的戰略自主性。

4. 文章中批判的「數位計算主義」是一種怎樣的科技意識形態？

這是一種主張宇宙萬物皆可被量化為離散數據，進而透過計算來預測、最佳化與操控一切的意識形態。作者認為這可能導致人類失去體驗世界的本真能力。
