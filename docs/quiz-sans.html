先想一下答案，再點開題目對照：

1. Delta 這款協作編碼環境的核心創新是什麼？它解決了傳統程式碼審查的什麼問題？

Delta 的核心創新是透過 DeltaDB 技術，將程式碼工作樹與對話進行即時同步。這解決了傳統基於提交的程式碼審查中評論容易過時的問題。

2. SpaceXAI 發布的 Grok 4.6 模型在人工智慧領域有何突出表現？它的主要優勢是什麼？

Grok 4.6 在「人工分析智慧指數」中獲得高分，與頂尖模型並駕齊驅，尤其在代理任務方面表現卓越。它的主要優勢是以顯著較低的成本提供了頂尖的智能表現，具有高成本效益。

3. 「HTML over WebSockets」這種建構單頁應用程式 (SPA) 的方法，與傳統方式相比有何主要不同？它帶來了什麼好處？

這種方法讓伺服器直接傳送預先構建好的 HTML，而非傳統的 JSON，大幅減少了客戶端 JavaScript 的需求。它透過 WebSocket 實現低延遲的即時通訊，並將所有渲染邏輯集中於後端處理。

4. 美國移民及海關執法局 (ICE) 計劃為其探員配備什麼新設備？此舉引起了哪些主要擔憂？

ICE 計劃為其探員配備可發出高達 380 伏特電擊的「低電壓發射手套」(GLOVE)。此舉引起民權組織的嚴重擔憂，認為可能加劇過度使用武力的問題並降低執法透明度。
