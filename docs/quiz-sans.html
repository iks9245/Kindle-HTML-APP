1. Meta AI 推出的 Muse Spark 1.3 模型，其核心架構與先前版本相比有何主要改變？

Muse Spark 1.3 模型從先前的自迴歸方法轉向採用了創新的擴散模型架構。這項改變旨在提升生成效率和圖片品質。

2. Fable 5.1 的世界建模系統如何能將真實地點精準重建為 3D 模型？這項技術有什麼獨特優勢？

Fable 5.1 利用自主式 Claude Fable 5.1 代理群體，根據開放資料和公開圖像自動生成 3D 模型。其主要優勢在於無需傳統遊戲引擎，所有模型都能在瀏覽器中直接探索。

3. 美國太空總署（NASA）的哈伯太空望遠鏡近期在土星的哪個半球觀測到了什麼樣的特殊大氣現象？

哈伯望遠鏡近期在土星的南極發現了一個巨大的、正在演變的十邊形大氣波。這是首次在土星南半球觀測到大型且規則邊緣的噴射氣流模式。

4. 沙烏地阿拉伯指控伊朗襲擊了其擁有的超級油輪，請問這起事件發生在哪個對全球能源供應至關重要的國際航運水域？

這起油輪襲擊事件發生在荷姆茲海峽。該水域因運輸著全球五分之一的石油和天然氣而對全球能源供應極為重要。
