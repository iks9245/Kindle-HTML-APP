1. Anthropic 的 Claude Code 團隊如何優化其程式碼審查流程以應對 AI 生成程式碼的龐大數量？

他們將大部分程式碼審查工作轉移到拉取請求開啟前由機器持續進行，並讓 Claude 處理例行性錯誤，使人類工程師能專注於更複雜的問題。

2. Home Assistant 的密碼洩漏檢查功能如何保護使用者隱私，以及使用者如何選擇停用此功能？

此功能在本地將密碼雜湊化，僅將雜湊值的前五個字元發送給 Have I Been Pwned (HIBP) 服務進行比對，完整的秘密資料不會離開使用者系統。使用者可透過 `ha security options --pwned=false` 指令停用。

3. 烏克蘭軍隊近期反攻行動的代號是什麼？在此次行動中，星鏈系統扮演了什麼關鍵角色，又發生了什麼問題？

烏克蘭軍隊的反攻行動代號為「韋瓦第行動」。星鏈系統在烏克蘭的空戰及指揮通訊中扮演關鍵角色，但在行動期間其軍用版「星盾」系統突遭限制，引發烏克蘭對關鍵技術依賴性的擔憂。

4. 哪位資深工程師被任命為 NASA 馬歇爾太空飛行中心主任？該中心在 NASA 哪個重要計畫中扮演核心角色？

資深工程師 Stephen Cash 被任命為 NASA 馬歇爾太空飛行中心主任。該中心在 NASA 的阿爾忒彌斯計畫中扮演核心角色，負責開發太空發射系統(SLS)火箭和人類登陸系統。
