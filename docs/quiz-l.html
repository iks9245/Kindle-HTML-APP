先想一下答案，再點開題目對照：

1. 一項關於Postgres資料庫查詢計畫最佳化的實驗取得了什麼顯著成果？

該實驗成功地讓一個小型語言模型為Postgres資料庫產生比其預設最佳化器快81%的查詢計畫。特別是針對連接繁重的查詢，實現了平均44.7%的延遲時間縮減。

2. 在「突破三元大型語言模型1.58位元障礙」的研究中，研究人員提出了哪種新型數據儲存佈局，並取得了什麼關鍵突破？

研究人員提出了名為BITCOS的新型數據儲存佈局，成功將三元LLM每權重儲存位元數降至1.485位元。這項創新打破了傳統1.58位元的限制，並能實現矩陣乘法加速。

3. 美國聯邦準備理事會（Fed）近期升息的主要原因是什麼，以及基準利率調整後的區間為何？

Fed升息的主要原因是為了對抗持續居高不下的通膨，因為通膨已超過2%的目標逾五年。此次升息將基準利率從3.5%-3.75%上調至3.75%-4%。

4. NASA位於關島的遙測站在遭受超級颱風「瑪娃」重創後，其恢復運作有何重要意義？

關島遙測站的恢復確保了低地球軌道太空船（包括國際太空站）與地球之間的持續通訊，避免了因颱風造成的「禁區」問題。這顯著降低了載人任務的通訊中斷風險。
