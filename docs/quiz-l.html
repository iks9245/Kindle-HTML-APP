先想一下答案，再點開題目對照：

1. Jev 公司發布的 1.14.0 版本中，若要啟用針對「夢想家」的實驗性功能，需要透過什麼方式來開啟？

這些實驗性功能需要透過 API 標頭中的「危險區域」旗標才能啟用。

2. 文章作者對 Anthropic 新推出的版本控制系統 Scion 的主要爭議點是什麼？

主要爭議點是 Scion 的核心設計與 Meta 近十年前開發的 Mononoke 系統高度相似，但 Anthropic 未能對 Mononoke 進行應有的歸屬致謝。

3. 根據馬斯克的說法，是誰可能限制了烏克蘭無人機透過星鏈的連線速度？他給出的理由是什麼？

馬斯克暗示美國政府可能是幕後黑手，因為星盾（Starshield）由美國政府控制，且他認為星鏈不應用於進攻性軍事行動。

4. 美國國家航空暨太空總署（NASA）即將進行的第100和第101次美國太空漫步的主要任務是什麼？

這些太空漫步的主要任務是安裝並部署最後兩個可捲曲式太陽能電池陣列（IROSA），以完成國際太空站的電力增強升級。
