1. 一位使用者如何利用AI工具將閒置的Kindle改造成數位相框？

2. 科學家們如何將來自高齡捐贈者的血細胞分子年齡逆轉至20歲以下？

莫納什大學的科學家們透過修改山中因子，進行瞬時且部分的重編程，將成年人血細胞轉化為具有年輕表觀遺傳年齡的幹細胞樣細胞。

3. 美國前總統川普宣布烏克蘭與俄羅斯達成「能源停火」協議後，俄羅斯採取了什麼行動？

4. 在當前的人工智慧革命中，「注意力」機制扮演了什麼關鍵角色？

「注意力」機制讓AI模型能動態聚焦於句子中最相關的詞彙以決定下一個輸出詞，此機制經Transformer架構強化後，大幅提升了語言模型處理效率，促成了ChatGPT等大型語言模型的發展。
