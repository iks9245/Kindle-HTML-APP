先想一下答案，再點開題目對照：

1. TypeSafe AI 發布的 Jev 模型主要用途為何？它與現有大型語言模型相比有何顯著優勢？

Jev 專為軟體提供快速、結構化的決策，以推動大規模自動化。相較於現有大型語言模型，Jev 在處理「System One 任務」時速度和效率高出兩個數量級，且專為結構化輸出優化，完全不會產生幻覺。

2. 德國軍工巨頭萊茵金屬開源了哪項關鍵技術？此舉對軍事技術領域有何重要意義？

萊茵金屬開源了其 Battlesuite 互聯武器系統協議的核心技術，即 `onboardapi` 介面庫和中間件。這對推動軍事技術的開放標準和互聯互通具有重要意義。

3. 開發者在約一個月內為 M4 晶片的 Mac Mini 成功開發出 Linux GPU 驅動程式，他們主要透過什麼方法達成這項成就？

這項成就主要透過嚴格的「潔淨室」方法，逆向工程 Apple 的 AGX GPU 韌體 ABI 和使用者空間元件來達成。全程避免直接檢視 Apple 二進制檔案，確保程式碼的獨立性。

4. 英國歌手紅髮艾德美國巡迴演唱會的所有暖場嘉賓為何集體退出？

他們退出是因為饒舌歌手麥可莫（Macklemore）因在舞台上發表親巴勒斯坦言論，被主辦方移除演出名單。此事件凸顯了藝人言論自由與巡演商業利益之間的緊張關係。
