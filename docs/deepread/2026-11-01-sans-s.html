脈絡

這篇文章深入探討了 CVE-2026-98432，一個影響 Linux 核心中 IPv4 TCP 握手的嚴重「使用後釋放」(use-after-free) 漏洞。此漏洞允許未經身份驗證的遠端攻擊者在應用程式處理連線之前，就能在幾乎所有 Linux 伺服器上觸發潛在的遠端程式碼執行。儘管上游核心已發布修復，許多主要發行版如 Ubuntu 和 Red Hat 在報導時仍未提供補丁。

重點

  • CVE-2026-98432 是一個評分高達 CVSS 9.8 的嚴重 Linux 核心漏洞。
  • 此漏洞是一個「使用後釋放」錯誤，發生在 IPv4 TCP 握手階段，可被遠端且未經身份驗證的用戶利用。
  • 它影響 Linux 核心 4.4 版本及之後的所有版本，並可能導致核心記憶體損壞或遠端程式碼執行。
  • Anthropic 的研究表明，AI 模型 Claude 已能建立一個針對啟用多路徑 TCP 伺服器的遠端 root 權限漏洞利用程式。
  • 截至 2026 年 10 月 31 日，許多廣泛使用的發行版（如 Ubuntu 和 Red Hat Enterprise Linux）的穩定版本仍未修復此關鍵漏洞。

影響與延伸

這個漏洞的嚴重性在於它存在於每個 Linux 伺服器在接受 IPv4 TCP 連線時都會執行的基本程式碼中，攻擊者無需任何憑證即可利用。企業和個人用戶必須立即檢查其 Linux 系統的更新狀態，並盡快應用補丁並重啟伺服器，以防止潛在的伺服器入侵和資料洩露。

小辭典

Use-after-free (UAF)
是一種記憶體錯誤，當程式嘗試存取已釋放的記憶體位址時發生。這可能導致程式崩潰、資料損壞或允許攻擊者執行任意程式碼。
TCP 握手 (TCP Handshake)
指的是在兩個主機之間建立 TCP 連線的三步驟過程（SYN, SYN-ACK, ACK），用於協商連線參數。
CVSS (Common Vulnerability Scoring System)
一個開放且通用的標準，用於評估電腦系統安全漏洞的嚴重性。分數越高，表示漏洞的嚴重性越高。
多路徑 TCP (Multipath TCP, MPTCP)
是 TCP 協定的擴展，允許 TCP 連線同時使用多個路徑。這可以提高網路效能、彈性和容錯能力，但在本案例中，如果啟用可能會使伺服器更容易受到特定利用。
