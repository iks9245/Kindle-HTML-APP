先想一下答案，再點開題目對照：

1. 生成式AI對網路開發教育者的商業模式造成了哪些衝擊？

生成式AI模型無償取用創作者內容，導致課程收入銳減、電子書需求暴跌，並讓許多同業被迫關閉業務，嚴重衝擊了他們的生計與創作動力。

2. 東北大學與Consumer Reports合作進行的連網汽車數據隱私研究，揭示了哪些主要問題？

研究顯示全球超過75%的連網汽車會持續將私人消費者數據傳輸給製造商和第三方，且消費者一旦數據離開設備後便失去控制權，數據常被出售給未公開的第三方。

3. 美國田納西州死囚 Christa Pike 的死刑執行發生了什麼意外，導致了什麼後果？

Christa Pike 在被施打了兩劑致命注射後仍倖存下來，目前情況危急。此事件導致田納西州州長下令暫停該州本年度所有死刑執行，並對執行方式展開第三方審查。

4. 美國太空總署（NASA）透過其「NASA+」平台為大眾提供了哪些免費資源？

NASA+ 平台提供免費、隨選的紀錄片，內容涵蓋從探索遙遠世界到了解行星防禦者等多元主題，讓大眾無需訂閱即可輕鬆參與太空探索與科學發現之旅。
