先想一下答案，再點開題目對照：

1. 電腦科學家瑪格麗特·漢密爾頓最廣為人知的成就是什麼，以及她對電腦科學領域有何深遠影響？

她領導了美國太空總署阿波羅計畫的軟體工程團隊，開發的軟體對人類首次登月任務至關重要。此外，她也奮鬥並成功地將「軟體工程」確立為一門獨立的學科。

2. Meta 和 Microsoft 為什麼會大幅減少員工對 Anthropic Claude AI 的內部使用？

此舉旨在轉向使用自家專有編碼工具，如 Microsoft 的 GitHub Copilot 和 Meta 的 MetaCode。這能更有效地管理 AI 支出並加強對內部解決方案的投資。

3. 西班牙87歲老婦人Maricarmen Abascal因何原因去世，以及她的故事引發了哪些重大的政治影響？

她因無法負擔租金上漲而被強制驅逐，並在住院後不幸去世，她的死再次點燃了全國對西班牙住房危機的抗議。此事件導致緊急住房法案被否決，並促使政府提前舉行大選。

4. 在「獨特博弈猜想」的研究中，人類研究團隊與AI之間發生了一場怎樣的「競賽」？

麻省理工學院的Dor Minzer團隊在OpenAI發布其AI生成證明前夕，緊急發表了他們對該猜想變體的證明。這突顯了AI在學術研究中日益增長的角色，以及它對人類研究過程的影響。
