Decisions API is in public beta

Decisions API 現已進入公開測試階段，能夠比 Responses API 快 10 倍的速度評估文字、圖像或兩者，並返回類型化的答案，用於內容分類、請求路由和工作優先排序。 此 API 提供三種問題類型：判斷式 (predicate) 用於檢查條件的真實機率、選擇式 (choice) 用於從固定選項中選取一個、分數式 (score) 用於依據評分標準進行評級。 * 目前僅支援 gpt-6-luna 模型。 * 計費方式為按輸入代幣計費，不收取快取讀寫或輸出代幣費用。

Decisions API 與現有的 Responses API 或其他結構化輸出方法有何不同？

Decisions API 專注於快速返回特定類型的答案，如判斷式、選擇式或分數式，以用於分類和優先排序。相較之下，Responses API 結合結構化輸出是用於根據自定義 JSON 結構生成物件，例如提取特定欄位或書面解釋，而函式調用則是模型調用外部工具的機制。

Decisions API 在實際應用中有哪些潛在用途？

Decisions API 可廣泛應用於自動化決策過程。例如，它可以自動檢查產品照片是否有可見損壞、將客戶投訴路由到正確的部門，或根據嚴重程度對客戶服務工單進行優先級排序，從而提高效率並減少人工干預。

使用 Decisions API 有哪些特定的限制或要求，尤其是在輸入類型或模型方面？

目前，Decisions API 僅支援 gpt-6-luna 模型。對於圖像輸入，它們必須是內聯的 Base64 資料 URL；此端點不支援託管的 HTTP 或 HTTPS 圖像 URL，也不支援 file_id 輸入。這確保了處理過程的效率和安全性。

Lunar Grounding Challenge

美國太空總署（NASA）正透過「月球接地挑戰」，尋求創新方案來解決太空人在月球南極進行艙外活動（EVA）時，太空衣因摩擦和電漿充電累積高負電荷的問題。尤其在月球陰影區和永久陰影區（PSRs）此問題更為嚴重，導致太空衣積聚顯著的負電位。當太空人帶著高電壓的太空衣返回略帶正電的著陸器時，極端的電壓差可能引發危險的靜電放電（ESD），這不僅會損壞太空衣和敏感電子設備，更威脅氧氣環境並可能對太空人造成電擊。該挑戰目標是在太空人接觸著陸器前，安全及時地中和其太空衣上的電荷，以確保未來月球任務的安全。 重點提示： • 靜電累積在月球表面行走及進入陰影區時尤為嚴重。 • 未解決的靜電放電會對太空人、太空衣及著陸器造成嚴重風險。

為何月球南極特別被提及為問題區域？

月球南極因其獨特的地理位置，擁有許多長期處於陰影中的區域（包括永久陰影區，PSRs）。在這些黑暗區域，太空衣缺乏環境離子通量和光電發射來平衡電子收集，導致負電荷累積問題更為嚴重，大幅增加了靜電放電的風險。

地球上或太空環境中，處理靜電通常有哪些方法？這些方法為何可能不適用於月球？

在地球上，靜電通常透過接地線、利用空氣濕度或使用導電材料來消散。太空船則可能透過與周圍電漿環境接地或設計導電路徑來管理靜電。然而，月球缺乏大氣層和濕度，且其獨特的表面粉塵、真空和電漿環境，使得這些傳統方法可能不足以安全有效地解決問題。

美國太空總署可能期待哪些類型的創新解決方案來應對此挑戰？

NASA可能期待從材料科學、系統設計和操作流程等多方面尋找解決方案。這可能包括開發新型抗靜電太空衣材料、設計用於太空衣或著陸器上的主動放電或中和裝置、或是制定一套在太空人與著陸器接觸前能安全消散電荷的標準操作程序。

參與者可以提供關於拍攝影像的衛星和儀器、使用的光譜波段，或者指出該地區地質或歷史的細微細節。分享該地點對個人的意義或任何引人注目的特點也會受到歡迎。

NASA Earth Observatory 舉辦這項每月挑戰的主要目的是什麼？

這項挑戰旨在鼓勵公眾深入觀察地球影像，提高他們對地球科學和衛星觀測的興趣。透過互動式的「拼圖」形式，NASA 希望能讓更多人參與了解我們地球的獨特之處。

參與者提交答案後會發生什麼？正確答案何時公布？

提交答案後，NASA Earth Observatory 會在大約一週後公布正確答案。他們會在頁面頂部揭示答案，並連結至一篇詳細解釋該影像的「每日地球觀測影像」故事，同時表揚第一位猜對者和分享特別見解的讀者。
