SAML: A fractal of bad design

「安全斷言標記語言」(SAML) 是一種自 2002 年起廣泛應用於學術界和企業 IT 部門的認證協議，為單一登入 (SSO) 服務奠定了基礎。然而，由於其設計上的複雜性，特別是在 XML 簽章驗證方面的脆弱性，作者認為 SAML 已成為「糟糕設計的碎形」，是時候退役了。文章呼籲組織應轉向現代替代方案，例如 OpenID Connect (OIDC)。 - SAML 的核心問題在於其基於 XML 的複雜性及 XML 簽章驗證的不可靠性，導致實作困難且存在安全隱患。 - OpenID Connect (OIDC) 因其更簡潔、更現代化的設計，被推薦為新整合和遷移的首選。

SAML 究竟是什麼，它最初的用途是什麼？

SAML 是「安全斷言標記語言」的縮寫，它是一種基於 XML 的標記語言，用於交換安全斷言資訊。它由 OASIS 於 2002 年創建，旨在為網路服務提供一種標準化的方式，讓使用者可以透過單一登入 (SSO) 驗證身份，特別是在 Web 2.0 初期學術界和企業對此需求旺盛。

為什麼 OpenID Connect (OIDC) 被認為是比 SAML 更好的替代方案？

OIDC 被視為更好的替代方案，主要是因為它比 SAML 更簡單、更現代。SAML 基於複雜的 XML，尤其其 XML 簽章驗證被認為是其核心問題和安全漏洞的來源，而 OIDC 則建立在更輕量級的 JSON Web Token (JWT) 和 OAuth 2.0 框架上，這使其更容易實作和維護，也較不易出現安全設計缺陷。

對於希望從 SAML 遷移的組織來說，有哪些建議的步驟？

對於服務供應商 (SP)，建議直接支援 OIDC 並避免使用 SAML。對於身份或認證供應商 (IdP)，則應制定詳細的淘汰計畫，包括向客戶溝通、停止為新客戶提供 SAML 整合、為現有客戶提供 OIDC 配置替代方案，並設定一個最終停用日期。

「減壓病（DCS）」、「靜脈血栓栓塞（VTE）」和「開放性卵圓孔（PFO）」在太空飛行中具體指的是什麼風險？

減壓病（DCS）是太空人因快速減壓導致體內氣體形成氣泡的風險。靜脈血栓栓塞（VTE）指血管內血栓形成。而開放性卵圓孔（PFO）是心臟結構上的小開口，可能讓氣泡或血栓從靜脈進入動脈循環，這三者都可能在太空飛行中危及太空人健康。

關於開放性卵圓孔（PFO），工作組對太空人的選拔標準和處理方式有何具體建議？

工作組認為PFO與靜脈血栓栓塞（VTE）的形成或其併發症沒有顯著關聯，因此不建議改變現有的太空人選拔標準。對於較大的PFO（3級或以上），專家意見不一，但工作組未建議普遍篩查或排除，而是強調通過協議設計和持續數據收集來進行風險緩解。如果太空人接受評估，應告知其PFO狀態並提供封閉手術的選擇。

為何艙外活動（EVA）前後的藥物使用需要明確的臨床指南？這對太空人的安全有何影響？

明確的藥物使用指南至關重要，因為某些止痛藥（如乙醯胺酚和布洛芬）可能掩蓋減壓病（DCS）的症狀，延誤診斷和治療。此外，指南也需涵蓋阿司匹林等藥物在預防DCS和緩解疼痛方面的使用。制定清晰的指南有助於確保太空人在EVA期間的健康與安全，並能及時應對潛在的醫療問題。

透過研究像「瀑布火焰變形蟲」這樣的嗜極生物，科學家能更深入了解地球生命生存的生物化學和生理極限。這有助於NASA擴展地外生命探索的範圍，指導他們在條件不如地球友好的其他星球上尋找可能存在的複雜生命。

除了溫度，對於這種在極端環境中生存的嗜極生物來說，還有哪些關鍵因素是不可或缺的？

研究人員指出，除了溫度，生存還取決於一個包含多種相互關聯因素的完整生態系統。這包括適當的酸鹼度、氧氣水平、壓力、充足的水源以及食物來源。「瀑布火焰變形蟲」無法單獨生存，它需要其他生命形式的支持才能存活。
