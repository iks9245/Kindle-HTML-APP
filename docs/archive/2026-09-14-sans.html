I'm being cyberattacked by Tesla, Inc

一名伺服器營運者自 8 月底以來，其 NTP 伺服器持續遭到來自 Amazon Web Services 的掃描流量攻擊，這些流量帶有 Assetnote 使用者代理並試圖執行多種漏洞利用（如 SSRF、Log4Shell）。調查後發現，這是因為 Tesla 的資產管理工具 Assetnote 誤將作者的伺服器識別為 Tesla 內部資產，原因是 `pool-ntp.tesla.com` CNAME 指向了 NTP Pool 伺服器，導致掃描器對非 Tesla 擁有的主機發動了攻擊。此問題現已解決。 * Tesla 的 CNAME 配置失誤導致第三方伺服器被誤認為內部資產。 * Assetnote 的自動化安全掃描器對無辜的外部主機發動了多種漏洞攻擊。

為什麼 Tesla 的資產管理工具會誤將外部伺服器識別為內部資產？

這是因為 Tesla 的 `pool-ntp.tesla.com` CNAME 紀錄指向了 `pool.ntp.org`，而後者會解析到數千個志願者提供的 NTP 伺服器。Tesla 的資產管理工具 Assetnote 在收錄 Tesla 網域下的所有資產時，錯誤地將這些 NTP Pool 伺服器的 IP 地址也納入了掃描範圍。

這種誤掃描行為可能帶來哪些潛在的安全風險？

儘管作者的伺服器沒有受到實際損害，但這種對陌生主機發動攻擊的行為，可能導致對無辜第三方服務的意外中斷、資源浪費，甚至在某些情況下，如果目標系統存在未知的漏洞，可能會因掃描活動本身而產生安全風險或揭露敏感資訊。

企業如何避免類似的資產識別錯誤，以防止對外部系統造成不必要的掃描？

企業應仔細審查其 DNS 配置，特別是 CNAME 記錄，確保資產發現工具不會將外部服務錯誤地納入內部資產範圍。同時，也應定期審核自動化掃描工具的配置，明確定義掃描範圍，並在執行活動掃描前進行充分測試，以避免對非目標系統產生副作用。

彗星NEOWISE為何被稱為「2020年大彗星」？

彗星NEOWISE因其在2020年7月出乎意料的亮度，成為北半球肉眼可見的壯觀天體，並持續數週，這在本世紀實屬罕見。它的高亮度和長時間的可見性使其在當時的夜空中脫穎而出，因此獲得了「大彗星」的稱號。

摘要中提到的「夜光雲」是什麼，與觀測彗星NEOWISE有何關係？

夜光雲是一種在極高層大氣中形成的冰晶雲，通常在夏季的黃昏或黎明時分可見，當太陽在地平線下時，它們仍能被陽光照亮而發光。在拍攝彗星NEOWISE的影像中，夜光雲為彗星升起時提供了引人注目的前景，增添了畫面的戲劇性和美感。

彗星NEOWISE何時會再次拜訪內太陽系，或者它有什麼樣的軌道？

彗星NEOWISE是一顆長週期彗星，根據計算其軌道週期約為6800年。這意味著它在內太陽系可見後將需要數千年才能再次返回，因此對於現代人類來說，2020年的觀測是一生中僅有一次的機會。
