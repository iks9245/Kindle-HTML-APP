先想一下答案，再點開題目對照：

1. Railway 最近披露的安全事件，建議使用者應立即採取什麼預防措施？

Railway 建議所有使用者立即輪換其所有的環境變數，包括 API 金鑰和私有登錄憑證，以保護系統。

2. Amazon Web Services (AWS) 最近發布的安全公告中，關於 PHP 網頁執行時環境的兩個嚴重漏洞要求客戶採取什麼行動？

受影響的客戶應立即將 PHP 升級至已修復的版本，例如 8.5.12，或儘速將已終止支援的版本遷移至受支援的分支。

3. 儘管俄羅斯原則上同意重啟烏克蘭和平談判，烏克蘭首都基輔當晚卻發生了什麼事件？

在俄羅斯原則上同意和談後，烏克蘭首都基輔卻在同一晚遭到導彈襲擊，造成六人受傷。

4. 美國國家航空暨太空總署（NASA）最近測試了哪種引擎，以支援未來的阿提米絲（Artemis）登月任務？

NASA 成功測試了編號 10001 的 RS-25 發展型引擎，此引擎將為太空發射系統 (SLS) 火箭提供動力，支援阿提米絲登月任務。
