Corals Spin Tiny Vortices to Get Oxygen, but Not if It’s Too Hot

珊瑚並非被動生物，它們透過微小的纖毛主動製造水流漩渦來獲取氧氣，尤其在夜間共生藻停止光合作用時。然而，最新研究顯示，當水溫升高時，水中溶氧量減少且珊瑚需氧量增加，導致纖毛加速擺動以嘗試補充氧氣。但若水溫持續上升超過臨界點，纖毛的劇烈擺動反而會消耗過多氧氣並輸送缺氧水體，最終導致珊瑚窒息死亡。這項發現揭示了氣候變遷下導致珊瑚死亡的關鍵新機制，強調缺氧與白化同為致命威脅，有助於解釋為何有些珊瑚在熱壓力下會死亡卻未白化。 關鍵重點： - 珊瑚纖毛是主動的氧氣供應機制，而非被動擴散。 - 高溫導致纖毛過度作功，造成自身缺氧窒息。 - 缺氧是高溫下珊瑚死亡的直接原因，提供白化以外的解釋。

珊瑚纖毛是什麼，它們具體是如何協助珊瑚獲取氧氣的？

纖毛是珊瑚表面微小的毛髮狀結構，能快速擺動以產生水流漩渦，將富氧海水帶到珊瑚組織。這項機制克服了氧氣在水中擴散緩慢的問題，同時也幫助清除代謝廢物和沉積物，對珊瑚的生存至關重要，尤其是在夜間共生藻停止光合作用時。

這項發現如何改變我們對珊瑚死亡原因的理解，與傳統的白化現象有何不同？

傳統上認為珊瑚主要因共生藻排出導致的白化而死亡。這項新研究則指出，在高溫下，即使沒有白化，珊瑚也可能因纖毛過度作功導致的自身缺氧而死。這揭示了另一個直接的致死機制，有助於解釋熱壓力下珊瑚死亡的複雜性，並強調缺氧是與白化同樣關鍵的威脅。

這項關於纖毛作用機制的發現，對於未來的珊瑚保育或研究有何潛在應用或下一步研究方向？

這項研究為理解珊瑚如何應對環境變化提供了新視角。未來的研究可以進一步探討纖毛運動的觸發機制，以及不同珊瑚物種對高溫下缺氧的抵抗力差異。這有助於開發更精準的珊瑚健康生物標誌物，並指導保育策略，以應對日益嚴峻的海洋熱浪挑戰。
