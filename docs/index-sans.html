作者的流程中包含一個關鍵步驟，即在LLM建立基礎知識庫後，會要求LLM自行審查其準確性。透過這種內部的驗證機制，並結合創建視覺化模擬，有助於減少錯誤和幻覺。

除了目前的低多邊形模擬外，作者提出了哪些改進或進階功能來優化這種學習方法？

作者建議可以將低多邊形設計轉化為更逼真的3D物件，以增加視覺的準確性。此外，他還提出在模擬中加入挑戰和直覺式謎題，透過回答問題和解決難題來進一步鞏固學習者的知識。

Saying No

Peter Block 將成人關係定義為「能夠提出你想要的，知道答案可能是『不』，然後協商差異」。這個概念啟發了作者，讓他在面對衝突和需要說「不」時，能夠更有勇氣地表達自己的需求並堅持立場。

對於作者而言，說「不」不僅是維護其作為租客的權利，更是對自身界限和需求的肯定。即便可能導致合約終止，作者認為在租賃時間內享有舒適且適合瑜伽練習的環境是基本權利，這比避免衝突更為重要。

讀者可以從作者的經驗中學習到，在面對要求或衝突時，要暫停思考「說不」是否是一個選項。Peter Block 的引言提醒我們，在成人關係中，說「不」是正常的，而雙方都應該預期並準備好協商差異，以建立更健康、更尊重的關係。
