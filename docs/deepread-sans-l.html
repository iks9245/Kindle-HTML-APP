脈絡

這篇文章是一份關於「Claude Code」工具的詳細更新日誌，涵蓋了從2025年4月到2026年9月的一系列新增功能、改進和錯誤修復。它揭示了該工具如何透過更靈活的配置選項、強化的代理互動能力和提升的用戶體驗，將Anthropic的Claude AI整合到開發工作流程中。這些更新旨在全面提高Claude Code的穩定性、功能性以及對開發者的友好度。

重點

  • 新增了對`AGENTS.md`文件的支援，作為`CLAUDE.md`的替代，用於配置專案中的Claude代理指令，提升了代理設定的靈活性。
  • 大量錯誤修復顯著改善了Claude Code的整體穩定性和可靠性，包括處理內部錯誤、對話問題及各種工具行為。
  • 引入了多項新的開發者工具和界面功能，例如新的網頁抓取工具、改進的MCP伺服器管理、檔案自動完成及自訂斜線命令。
  • 新增了「思考模式」（如「think」、「ultrathink」），讓Claude能進行更深入的規劃與推理，以應對複雜任務。
  • 強化了Claude應用程式閘道器和外掛程式的配置選項，賦予用戶更大的控制權和定制能力。

影響與延伸

這些更新表明Claude Code正朝著成為一個更強大、更具彈性的AI輔助開發工具邁進，特別是在管理和整合AI代理於專案中的能力。透過提供更豐富的配置選項和先進的AI推理模式，開發者將能更有效地利用Claude來解決複雜的程式設計和協作挑戰。持續的穩定性改進和新工具的加入也預示著其在開發者生態系統中將扮演更為核心的角色。

小辭典

Claude Code
一款整合Anthropic的Claude AI到開發環境中的工具，支援程式碼編輯、代理互動等多種功能，旨在提升開發者的生產力。
AGENTS.md / CLAUDE.md
專案中用於存放給Claude AI代理指令或背景資訊的Markdown文件，指導其在專案中的行為和上下文理解。
MCP (Managed Compute Platform)
一種管理運算資源或服務的平台，在此文中指涉其伺服器配置和管理功能，可能與Claude AI的運行環境或擴展服務相關。
思考模式 (Thinking mode)
Claude AI的新功能，允許其在處理請求前進行更深入、有結構的規劃和推理，以生成更精確或全面的回應。
